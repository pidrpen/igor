# Облачные сохранения — подключить один раз

Вход по логину и паролю, почта не нужна. Бесплатного тарифа Supabase хватает с запасом.

## 1. Завести базу (5 минут)

1. Зайди на **supabase.com** → Sign in (можно через GitHub) → **New project**.
   Имя любое, пароль базы придумай и сохрани (игре он не нужен), регион — ближайший (Frankfurt).
2. Слева **SQL Editor** → **New query** → вставь целиком `Тест/облако/supabase.sql` → **Run**.
   Должно написать «Success». Повторный запуск ничего не ломает.
3. Слева **Project Settings** → **API** (или **API Keys**). Нужны два значения:
   - **Project URL** — вида `https://abcdefgh.supabase.co`
   - ключ **anon public** (или **publishable**) — длинная строка.

   Ключ **service_role / secret** не нужен и в игру его класть нельзя: игра с ним откажется работать.

## 2. Вписать в игру

`Тест/js/cloud-config.js`:

```js
window.MK_CLOUD = {
  url: 'https://abcdefgh.supabase.co',
  anonKey: 'eyJhbGciOi...',
};
```

Или просто пришли эти два значения — впишу и запушу. Ключ anon публичный, его можно держать в репозитории:
сам по себе он даёт только вызвать функции входа и сейва, а таблицы закрыты.

## Как это работает для игрока

- Лобби, под «Экспорт / Импорт сейва» → **Войти или создать аккаунт**.
- Пока вошёл, сейв раз в 30 с и при сворачивании окна уходит в облако: отряд, шмот, общая сумка,
  таверна, история, лучший ключ, ключ в процессе. Тот же набор, что «Экспорт сейва».
- На другом компьютере входишь тем же логином — сейв приезжает.
- Если в облаке сейв новее того, от которого ты играешь (играл на другом компьютере), игра ничего
  не затирает и спрашивает, какой оставить.
- Пароль хранится в базе только хешем (bcrypt). 10 неверных паролей подряд — вход на паузе 5 минут.
- Облако пустое в `cloud-config.js` — всё как раньше, сейв только на этом компьютере.

Посмотреть игроков и сейвы: Supabase → **Table Editor** → `mk_players`, `mk_saves`.
Сбросить пароль игроку: удалить его строку в `mk_players` (сейв удалится вместе с ней) — пусть
зарегистрируется заново, или попроси — сделаю функцию смены пароля.
