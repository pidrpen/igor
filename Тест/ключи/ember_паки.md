# Угольные Чертоги — паки

Только дизайн. Код, `theme.ember` в `enemies.js` и основу не трогать, пока не скажешь вшить.

Данж `ember`, тема `ember`. Таймер **29 мин**. Отряд: **1** танк, **1** целитель, **3** бойца.

Лицо пака — **уголь несут и кладут**. Жар чертогов — шкала **зала 0–8 стаков**, не стаки каста. Прерывание шкалу **не** обнуляет.

Босс-механики — в `ember_механики.md`. Этот файл — дом сетки, юнитов и составов. Если вес пака расходится с таблицей в механиках или с `enemies.js`, верен **этот** файл.

Базы — шаблон до шкалы ключа и `STAT_SCALE`. Урон врага: **атака × вес**, не «т» героя. Чистый урон броню не режет. Лечение героя — в **т** или в **% max HP** цели.

Вшить — потом, по слову. **1–9**, затем клик.

## Зачем этот файл

Сейчас в `theme.ember` Пепельный громила — копия Шлакового громилы до правки Кузни.

| Кто | База | Авто | Вторая кнопка | Сырой счёт |
|---|---|---|---|---|
| Пепельный громила сейчас | **148 HP**, атака **14**, защита **9**, скорость **6** | Удар угля **1.15 × атаки** | Обвал жара область **0.52 × атаки**, перезарядка **2 хода** | **14 × 1.15 = 16.1** в угрозу; область **14 × 0.52 = 7.3** на каждого |
| Шлаковый громила (старый) | **145 HP**, атака **14** | Удар **1.15 × атаки** | Топот горна **0.50 × атаки** | **16.1** / **7.0** |

Его оставляют на потом и забывают. Жара зала нет. Угля не несут. Кик Извержения ничего в печи не меняет.

Цель: Пепельный громила — печь комнаты. Пока он жив и уголь не положили, Жар чертогов ползёт, его удар жиреет, входящий по нему падает, Обвал жара просит стену. Остужает только клик с углём в руках.

## Чем это не Кузня и не боссы целиком

Кузня остужает **Жар горна** прерыванием: кик **−1 стак**, промах **+1 стак**, на Шлаковом исполине успешный Перекал ставит шкалу в **0**. Шлаковый громила жжёт Выплеском корки, если стену не нажали.

Чертоги так не строить.

- Прерывание **не** опускает Жар чертогов. Кик только не даёт **+1 стак** за пропуск Извержения.
- Остужает положенный Остывший уголь: область и смешанный — в **Зольный жёлоб**; СТ — в **Угольного колосса**.
- Лекаря врага в пулле нет (это Склеп и Приливник).
- На паки **не** вешать: Топку чертогов, Клеймо надсмотрщика, Корпус из угля на **3** загрузки, Раскалённое ядро, Перегрев, Живую бомбу, Жаркий очаг Кузни, вентиль Приливника.

Жар и уголь на паке — короткая версия. Клеймо, корпус на **3** загрузки и ядро остаются миду и финалу.

| | Пепельная Кузня | Угольные Чертоги, пак |
|---|---|---|
| Таймер | **27 мин** | **29 мин** |
| Шкала | Жар горна **0–3** | Жар чертогов **0–8** |
| Как падает | успешное прерывание **−1 стак** | положить Остывший уголь |
| Толстый в области | Шлаковый громила, Выплеск корки | Пепельный громила, печь и глоток угля |
| Что бить первым | Искрового пироманта | живого Уголька одиночным, затем жёлоб |
| Объект в ряду | нет | Зольный жёлоб (не треш, сил не даёт) |

Имена на карте случайные (Тлеющий, Угольный, Пепельный, Раскалённый, Зольный, Жаркий, Обугленный, Искрящий + страж / голем / исполин / вихрь / уголёк / надсмотрщик / осколок). Слоты составов ниже **не** мешать и не брать из пула Кузни.

## Как отвечать

Бой всегда: способность **1–9**, затем клик по портрету цели. Автоцели и автоудара нет. Без выбранной способности клик ничего не назначает.

- Урон, ослабление, область по врагам: **1–9** → клик по врагу. Область тоже просит клик по любому живому врагу в пулле.
- Прерывание: **1–9** → клик по кастеру с телеграфом «Прерывание». Сбитие: Немота **2 хода**, эскалация в **0**. Пропуск: каст проходит, эскалация **+18 %** за промах, потолок **+75 %**, Жар чертогов **+1 стак**. Шкала от кика **не** падает.
- Положить уголь, область и смешанный: одиночный урон **1–9** → клик по **Зольному жёлобу**.
- Положить уголь, СТ: одиночный урон **1–9** → клик по **Угольному колоссу**.
- Передать уголь: одиночная способность **1–9** → клик по живому союзнику (не пет).
- Удар по танку: танк жмёт крупную защиту (Глухая оборона, Божественная защита, Незыблемость льда, Дубовая кожа, Стойкость хмелевара, Ускользание). Самоцель: второй клик не нужен. Если угроза не на танке — сначала Провокация (самоцель). Крупная защита режет удар до **45 %**. Промах мимо танка: ещё **+25 %**.
- Хил, внешний щит, снятие Раскалённых лат: **1–9** → клик по союзнику.
- Жрец Свет, Послушание, Ткач туманов, рыцарь смерти — без прерывания. Кик держат остальные в пятёрке.

Целитель развеивание иметь не обязан. Раскалённые латы снимает лечение по клику.

## Жар чертогов на паке

Шкала **0–8 стаков** на карточке старшего врага: Пепельный громила, иначе Раскалённый берсерк, иначе Угольный колосс. Старт пака: **1 стак** (у боссов старт **2 стака**).

| Стаки | Что происходит |
|---|---|
| 0–2 | Входящий по Пепельному громиле и по Угольному колоссу без корки как обычно. Уголь сырой. |
| 3–5 | Норма. Сюда надо вернуть шкалу. Пепельный громила уже бьёт жирнее и чуть танковее. |
| 6–7 | Входящий огонь по отряду **+15 %** (у боссов **+20 %**). Угольный колосс на Раскале жирнеет. |
| 8 | **Выгорание зала:** сразу **12 %** max HP всем (у боссов **18 %**). Пока шкала **8**, в конце каждого раунда ещё **6 %** max HP всем (у боссов **8 %**), пока уголь не положат. |

Как растёт:

- Живой Уголёк (или Живой уголёк на СТ) дожил до своего хода: **+1 стак**.
- Этого уголька убили областью или периодическим уроном по площади: **+2 стака** и вспышка **6 %** max HP отряду (у боссов вспышка **8 %**).
- Остывший уголь истёк за **3 хода**: **+1 стак**.
- Пропущенное **Извержение**: **+1 стак**. Кик стаки не снимает.
- Пепельный громила в начале своего хода, Жар чертогов **0–2**, за этот раунд уголь никуда не клали: **+1 стак**.
- Глоток угля (клик по Пепельному громиле с углём в руках): **+1 стак**.
- Пропущенный **Обвал жара** без крупной защиты: **+1 стак** (у Титана **+2 стака**).

Как падает — только положенный уголь:

- Область и смешанный: одиночный урон → клик по Зольному жёлобу. Уголь тратится. Жар чертогов **−2 стака**.
- СТ: одиночный урон → клик по Угольному колоссу. Удар проходит **и** даёт **1** загрузку Угольной корки. Жар чертогов **−1 стак**.
- Голый удар по жёлобу без Остывшего угля шкалу не двигает. Это не вентиль Приливника.

## Живой уголь на паке

Не бомба Разлома. Не Раскалённый слиток Кузни. Не адд, который лечит босса фактом жизни.

**Один уголь в отряде.** Пока на ком-то висит Остывший уголь, второй не выдают.

**Кто даёт уголь.** В каждом паке области и смешанном ровно **один** Уголёк — живой. Остальные Угольки угля не дают: их после живого можно бить областью. На СТ уголь даёт **Живой уголёк** (**43 HP**, **55 %** от **78 HP** шаблона Уголёк), не треш.

**Убийство одиночным.** **1–9** одиночный урон → клик по живому угольку. Убийца получает **Остывший уголь на 3 хода**. Если уголь в отряде уже есть: нового нет, Жар чертогов **+1 стак**, вспышка **5 %** max HP убийце.

**Убийство областью.** Адд мёртв, угля нет, Жар чертогов **+2 стака**, вспышка **6 %** max HP отряду.

**Пока несёшь.** В конце хода носителя: **3 %** его max HP огнём, чистый. Если **3 хода** вышли: вспышка **8 %** max HP носителю (у боссов **10 %**), Жар чертогов **+1 стак**, бафф снят.

**Передача.** Носитель: одиночная способность **1–9** → клик по живому союзнику (не пет). Уголь переезжает, таймер снова **3 хода**. Область уголь не передаёт. Лечение при передаче всё равно лечит кликнутого.

**Вырвать уголь.** Один раз за бой, если Жар чертогов **≥ 4 стака** и в отряде нет Остывшего угля: одиночный урон **1–9** → клик по **Пепельному громиле**. Удар проходит **и** атакующий получает Остывший уголь на **3 хода**. Это второй уголь пака, из танка, когда печь уже разогналась. Пока уголь в руках, тот же клик — глоток, не вырывание. На СТ Пепельного громилы нет — вырывать не из кого.

Как у ключа `descent-v2`. Силы — бюджет узла. Боссы сил не дают.

| Жаркий очаг · СТ | чемпион | **28 %** | состав 3 | Имя узла — не Жаркий очаг Кузни. Тот же Угольный колосс |

| Трон — Угольный Титан | босс | **0 %** | не этот файл | Корпус, ядро, латы |
| Добор: двор | область | **12 %** | состав 1 | Добор сил |
| Добор: чемпион · СТ | чемпион | **18 %** | состав 3 | Повтор колосса |
| Добор: склеп | смешанный | **12 %** | состав 2 | Имя узла старое. Тела чертогов |

Число тел:

- **Область:** **4** треша. С ключа **5** — ещё **+1**. С ключа **10** общая сетка просит ещё **+1**, в Чертогах этот шестой треш **не** ставится: потолок карт **6** вместе с жёлобом.
- **Смешанный:** **1** элита + **2** треша. С ключа **10** — третий треш.
- **СТ:** один чемпион. HP **×1.55** к базе, атака **×1.10**. С ключа **12** рядом **1** обычный Уголёк (угля не даёт).

**Зольный жёлоб** — объект. В счёт **4 / 5 / 6** треша не входит, сил не даёт, убить нельзя. На СТ жёлоба нет.

Не ставить в одну комнату двух Раскалённых берсерков. Не ставить двух чемпионов. Не подменять состав случайным пулом.

## Три состава

Не четыре случайных Уголька. Не «пиромант + громила + молотобоец».

### Состав 1 — Зола в руках

Область. Учит нести и класть.

База (**4** тела + жёлоб): **1** Пепельный громила + **1** живой Уголёк + **2** обычных Уголька + **1** Зольный жёлоб. Карт **5**.

- Ключ **5**: **+1** обычный Уголёк. Итого **5** тел + жёлоб. Карт **6**.
- Ключ **10**: шестого тела нет.

Врата, Коридор, Зольный проход, Пепельный зал, Добор: двор.

Порядок кликов:

1. Живой Уголёк: одиночный урон **1–9** → клик по нему.
2. Остывший уголь: одиночный урон **1–9** → клик по Зольному жёлобу. Не по Пепельному громиле.
3. Обвал жара: крупная защита танка, самоцель. Если угроза не на танке — сначала Провокация (самоцель).
4. Обычных Угольков после живого можно бить областью. Пепельный громила последним — пока Жар чертогов не **≥ 4 стака** без угля в руках: тогда один одиночный в него (вырвать) и снова жёлоб.

Прерывания в этом составе нет.

### Состав 2 — Печь и Извержение

Смешанный. Учит: кик не гасит жар.

База: **1** Раскалённый берсерк + **1** Пепельный громила + **1** живой Уголёк + **1** Зольный жёлоб. Карт **4**.

- Ключ **10**: **+1** обычный Уголёк. Карт **5**.

Спуск, Добор: склеп.

Порядок кликов:

1. Живой Уголёк одиночным → жёлоб, как в составе 1.
2. Извержение: прерывание **1–9** → клик по Раскалённому берсерку. Кик жар не опускает. Пропуск даёт область вес **0.90** и Жар чертогов **+1 стак**; если каст ещё и убил живого Уголька — это убийство площадью (угля нет, **+2 стака**, вспышка **6 %** max HP).
3. Обвал жара — стена, как в составе 1.
4. Резать Раскалённого берсерка, пока не читает. Пепельный громила последним, если печь не разогналась.

Не бить Раскалённого берсерка областью, пока живой Уголёк на поле.

### Состав 3 — Уголь в чемпиона

СТ. Учит класть уголь в толстого — репетиция Угольного Титана, без ядра.

**1** Угольный колосс (HP **×1.55**, атака **×1.10**). Жёлоба нет.

- Угольный колосс · СТ, Жаркий очаг · СТ, Добор: чемпион · СТ: Живой уголёк (**43 HP**) на раунде **2**. Пока жив — нового нет.
- Преддверие · СТ: тот же Живой уголёк **с старта**.
- Ключ **12**: + **1** обычный Уголёк с старта (угля не даёт).

Порядок кликов:

1. Живой уголёк: одиночный урон **1–9** → клик по нему.
2. Остывший уголь: одиночный урон **1–9** → клик по **Угольному колоссу** (загрузка корки, жар **−1 стак**). Не по обычному Угольку.
3. Повтор, когда выйдет второй уголёк. Нужно **2 загрузки**.
4. Обвал жара: крупная защита танка, самоцель.
5. Раскал на Жаре чертогов **6+** — лечение в танка заранее. Пока корка цела, бить колосса без угля в руках слабо.

Вырвать уголь на СТ нельзя: Пепельного громилы в составе нет. Промах по живому угольку областью оставляет чемпиона в корке и гонит жар к **8**.

## Юниты

Роль «танк» здесь — враг, который бьёт угрозу и наказывает игнор печи. Не танк отряда.

Правило танк-моба: автоудар вес **1.10–1.15** плюс область вес **0.50** как единственная угроза — запрещены. Пепельный громила несёт бастер, клев по носителю угля и печь, которую игнор разгоняет.

### Уголёк — треш, боец

**78 HP**, атака **14**, защита **3**, скорость **11**.

В паке области и смешанном **один** Уголёк помечен как живой (уголь). Остальные — только Искра и Зола.

| Способность | Вес | Куда | Перезарядка | Школа | Заметка |
|---|---|---|---|---|---|
| Искра | **1.10** | угроза | каждый его ход | огонь | **14 × 1.10 = 15.4** |
| Зола | **0.50** | все живые герои | **2 хода** | огонь | **14 × 0.50 = 7.0** на каждого. Телеграфа нет. Если добила живого Уголька — убийство площадью |

Ответ: живого — одиночный **1–9** → клик по нему. Обычных после этого можно клевать областью.

### Пепельный громила — треш, танк-моб

Сейчас: **148 HP**, атака **14**, защита **9**, скорость **6**, Удар угля вес **1.15**, Обвал жара область вес **0.52**. Слабо.

База нужна: **172 HP**, атака **16**, защита **10**, скорость **6**, мана **20**. Роль танк.

| Жар чертогов | Вес Удара угля | Сырой удар (атака **16**) | Пепельный панцирь |
|---|---|---|---|
| 0–2 стака | **1.40** | **22.4** | нет |
| 3–5 стаков | **1.60** | **25.6** | входящий **−10 %** |
| 6–7 стаков | **1.80** | **28.8** | входящий **−20 %** |
| 8 стаков | **2.00** | **32.0** | входящий **−25 %** |

Было **14 × 1.15 = 16.1**. На низком жаре уже жирнее. На высоком — почти вдвое.

| Способность | Вес | Куда | Перезарядка | Школа | Заметка |
|---|---|---|---|---|---|
| Удар угля | из таблицы жара | угроза | каждый его ход | огонь | если кто-то несёт Остывший уголь — носитель сверх того получает **4 %** своего max HP огнём, чистый |
| Обвал жара | **1.15** | угроза | **3 хода** | огонь | телеграф «Удар по танку», приоритет **2**, цена **10** маны, чтение **1 ход**, киком не сбить. В разрешении: **атака × 1.15 × 1.45**. **16 × 1.15 × 1.45 = 26.7**. Было область **14 × 0.52 = 7.3** на каждого |

Обвал жара в разрешении:

- крупная защита до разрешения режет удар до **45 %**: **16 × 1.15 × 1.45 × 0.45 = 12.0**. Раскалённых лат нет. Жар от этого удара не растёт;
- без стены: удар проходит (**26.7**), **Раскалённые латы +1 стак**, Жар чертогов **+1 стак**;
- промах мимо танка: ещё **+25 %** (**16 × 1.15 × 1.45 × 1.25 = 33.4**) и латы с жаром всё равно.

Раскалённые латы на паке: максимум **2 стака**, длительность **3 хода** (у Титана максимум **3 стака**, **4 хода**). Каждый стак в начале хода танка: **5 %** его max HP огнём, чистый (у Титана **7 %**). Снятие: лечение не ниже **10 %** max HP танка, **1–9** → клик по танку = **−1 стак** (у Титана порог **12 %**). На **2 стаках** следующий Удар угля по танку **+40 %** (у Титана на **3 стаках** **+60 %** и **1 ход** без защитных).

**Глоток угля.** Одиночный урон по Пепельному громиле, пока у кликнувшего есть Остывший уголь: уголь сгорает, лечение **5 %** max HP Пепельного громилы, Жар чертогов **+1 стак**, следующий Удар угля **+40 %** один раз. Это урок мида: не кормить толстого углем.

Игнор портрета («бьём Угольков областью, плиту потом») здесь наказывается не щитом Склепа и не киком Кузни. Наказывается расписанием: он сам раздувает жар, толстеет панцирем, бьёт носителя угля и вешает латы.

Ответ: танк держит угрозу. Перед Обвалом жара — крупная защита, самоцель. Целитель кликает танка, если висят Раскалённые латы. Кикер в Пепельного громилу не кликает: телеграф не «Прерывание».

### Зольный жёлоб — объект

Не Топка чертогов. Не Жаркий очаг Кузни. Стоит с начала боя в ряду врагов на области и смешанном. Убить нельзя. Без Остывшего угля удар ничего не делает. С углём: одиночный урон **1–9** → клик по жёлобу — уголь тратится, Жар чертогов **−2 стака**. Урон жёлобу не важен.

На СТ жёлоба нет.

### Раскалённый берсерк — элита, боец

**210 HP**, атака **21**, защита **5**, скорость **12**, мана **45**. Лекаря и призыва нет.

| Способность | Вес | Куда | Перезарядка | Школа | Заметка |
|---|---|---|---|---|---|
| Яростный удар | **1.30**; при Жаре **6–7** или **8** — **1.50** | угроза | каждый его ход | огонь | **21 × 1.30 = 27.3**; на высоком жаре **21 × 1.50 = 31.5**. Едет на печи Пепельного громилы |
| Берсерк | — | себя | **4 хода** | — | **+30 %** атаки на **2 хода**. С Берсерком Яростный удар **27.3 × 1.30 = 35.5** |
| Извержение | **0.90** | все живые герои | **3 хода** | огонь | телеграф «Прерывание», приоритет **3**, цена **12** маны, чтение **1 ход**. **21 × 0.90 = 18.9** на каждого, если прошло |

Пропуск: область **атака × 0.90 × эскалация** и Жар чертогов **+1 стак**. Сбитие: Немота **2 хода**, эскалация в **0**, жар **не** падает.

Ответ: прерывание **1–9** → клик по Раскалённому берсерку, пока читает. Тело режут после живого Уголька и после каста, не вместо них.

На СТ-узле Раскалённый берсерк не чемпион. Чемпион — только состав 3.

### Угольный колосс — чемпион СТ, танк

База: **340 HP**, атака **20**, защита **16**, скорость **5**, мана **25**. В комнате СТ: **527 HP** (**340 × 1.55**), атака **22** (**20 × 1.10**).

Не Шлаковый исполин: у того Перекал сбивают киком и этим остужают зал. У колосса кика, который остужает зал, нет. Уголь кладут **в него**.

С боя в **Угольной корке**: входящий **−25 %** (у Титана Угольная броня **−40 %**). Нужно **2 загрузки** (у Титана **3**). На 2-й загрузке корка спадает на **3 хода** (у Титана **4 хода**): входящий **+15 %** (у Титана **+25 %**), Жар чертогов **−1 стак** за сам разлом. Потом корка возвращается, счётчик обнуляется.

| Способность | Вес | Куда | Перезарядка | Школа | Заметка |
|---|---|---|---|---|---|
| Удар угля | **1.55**; при Жаре **6–7** или **8** — **1.75** | угроза | каждый его ход | огонь | при атаке **22**: **34.1** / **38.5** |
| Раскал | **2.10**; при Жаре **6–7** или **8** — **2.40** | угроза | **2 хода** | огонь | при атаке **22**: **46.2** / **52.8**. Не казнь ниже **35 %** HP |
| Обвал жара | **1.05** | угроза | **3 хода** | огонь | телеграф «Удар по танку», приоритет **2**, цена **14** маны. В разрешении: **атака × 1.05 × 1.45**. При атаке **22**: **33.5**. Латы как у Пепельного громилы (пак: максимум **2 стака**, тик **5 %** max HP, снятие **≥ 10 %** max HP). У Титана вес **1.15** / **1.20** |

Ядра нет. Топки нет. Клейма нет.

Ответ: Живой уголёк одиночным, затем одиночный в Угольного колосса. Стена в Обвал жара. Кикер в колосса не кликает, пока нет телеграфа «Прерывание» — его здесь нет.

### Живой уголёк — адд СТ

**43 HP** (**55 %** от **78 HP** Уголька). Атаки нет, хода как бойца нет: если дожил до своей очереди — только Жар чертогов **+1 стак**. Убийство одиночным / областью — как в разделе угля. На области этот адд не ставится: там живой — обычный Уголёк **78 HP**.

## Стыковка танка с углём и жаром

Пока Пепельный громила жив:

| Состояние зала | Что он делает |
|---|---|
| Жар **0–2**, уголь в этот раунд не клали | в свой ход **+1 стак** жара |
| Жар **3–5** | Удар угля **1.60 × атаки** (**25.6**), входящий **−10 %** |
| Жар **6–7** | Удар угля **1.80 × атаки** (**28.8**), входящий **−20 %**, огонь по отряду **+15 %** |
| Жар **8** | Удар угля **2.00 × атаки** (**32.0**), входящий **−25 %**, зал горит |
| В отряде Остывший уголь | Удар угля жжёт носителя на **4 %** max HP сверх угрозы |
| Клик по нему с углём | глоток: **5 %** max HP себе, жар **+1**, следующий Удар угля **+40 %** |
| Жар **≥ 4**, угля в отряде нет | один раз за бой одиночный в него вырывает уголь |
| Обвал жара без стены | Раскалённые латы **+1** и жар **+1** |

Раскалённый берсерк и Угольный колосс на том же жаре жирнеют сами. Остудил зал — остудил всю комнату. Кик этого не делает.

## Сводка кликов

| Что видишь | Клавиша 1–9 | Клик |
|---|---|---|
| Живой Уголёк / Живой уголёк | одиночный урон | этот уголёк |
| Остывший уголь, область или смешанный | одиночный урон | Зольный жёлоб |
| Остывший уголь, СТ | одиночный урон | Угольный колосс |
| Уголь не у того героя | одиночная способность | союзник, который понесёт |
| Жар **≥ 4**, угля нет, Пепельный громила жив, вырывание ещё не тратили | одиночный урон | Пепельный громила |
| Извержение | прерывание | Раскалённый берсерк |
| Обвал жара сейчас | крупная защита танка | без клика / свой портрет |
| Раскалённые латы | лечение **≥ 10 %** max HP | танк |
| Нельзя | область по живому Угольку | — |
| Нельзя | урон по Пепельному громиле с углём в руках | Пепельный громила |
| Нельзя | клик без способности | любой портрет |
| Нельзя | прерывание «снять жар» | любой кастер |

Один ход — одна кнопка и один клик. Уголька и жёлоб / колосса за один ход не закрыть: сначала убить, на следующем ходу (или ходу союзника после передачи) положить.

## Чего на паке нет

Топки чертогов, Клейма надсмотрщика, Корпуса из угля на **3** загрузки, Раскалённого ядра, Излива жара, Кнута пепла, Взрыва углей.

Второго танка, Перегрузки, проводников, сфер голым кликом.

Прерывания, которое обнуляет Жар чертогов. Живой бомбы и Перекала Кузни. Выплеска корки и Окалины Кузни.

Лекаря в пулле.
