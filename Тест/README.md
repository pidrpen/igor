# Mythic Key — тестовая сборка

Рабочая копия игры. Новые правки идут сюда, на основу (корень репозитория) переносятся по слову «перелив».

Сверх основы здесь: магазин шмота (`js/shop/`), живой бой в реальном времени (`js/live/`, кнопка в лобби), облачный сейв (`js/cloud.js`, база — `облако/`), поле 3×2 (выключено).

## Запуск

Сервер из корня репозитория — так открываются обе сборки и ссылка «← Основная игра»:

```bash
python -m http.server 8080
# http://localhost:8080/Тест/
```

## Тесты

```bash
node tests/load-check.js && node tests/balance-smoke.js
node tests/dot-per-caster-smoke.js && node tests/engine-sheet-smoke.js
```

Правила и карта файлов — `../AGENTS.md`.
