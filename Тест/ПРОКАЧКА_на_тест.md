## 1. Что уже решено (не выдумывать заново)

Из концепта паладина это закон и для Теста:

1. Ключ — финал. Прокачка — слой **до** ключа, не второй ключ и не рогалик.
2. Один герой. Спек при создании. Переспек = новый герой (сброс).
3. 40-й = текущие `spec.stats` из кита Теста (`STAT_SCALE` 1000). Шмот ключа — поверх, после 40.
4. Кривая: `доля = 0.22 + 0.78 × ((ур−1)/39)^1.12`. Опыт: `round(36 × ур^1.12 + 22)`.
5. ≈ 20–24 коротких инста с 1 до 40. Вайп — 20% опыта захода, герой жив.
6. Таланты героя ≠ силы ключа (`Закалённая сталь` и т.п. остаются на один заход ключа).
7. ИИ на один инст, добивают роли, после инста растворяются. Игрок ходит только своим.
8. Скорость только очередь. Второй ход не давать.
9. В прокачке шмота сначала нет — иначе не видно, растёт уровень или кольцо.
10. **S37 Изобретатель не трогаем** — ни деревом, ни кривой, ни «подтянуть остальных».

Песочница `прокачка/` — черновик этой связки на одном паладине. Движок ключа она **не** импортирует. Цифры паладина там скопированы руками — при правке кита песочница протухает. На Тесте так больше не делать.

---

## 2. Как это должно жить в Тесте (дом)

Не тащить папку `прокачка/` внутрь `Тест/index.html`. Это другой бой, другой сейв, чужой кит.

Когда скажешь «делай в Тесте»:

| Слой | Куда |
|---|---|
| Кривая, опыт, скобки данжей | `Тест/js/leveling/curve.js` (чистые функции, без DOM) |
| Открытие кнопок по уровню | `Тест/js/leveling/unlocks.js` — читает **живой** `class-balance/*`, не копию |
| Дерево героя | `Тест/js/leveling/hero-talents.js` |
| Сейв героя | `Тест/js/leveling/hero-save.js` + крючок в `save.js` **отдельным ключом** |
| Таверна / очередь / короткий инст | `Тест/js/leveling/hub.js` + экран в лобби |
| ИИ союзников инста | обобщить `raidAllyAi` → `partyAi`, урезанный кит 3–5 кнопок |

Бой инста — тот же движок Теста (`abilities`, `damage`, `combat-loop`). Не второй `engine.js`.

Лобби ключа не ломать: пока герой < 40 — кнопка «Таверна», ключ серый. На 40-м ключ открыт, первый слот — этот герой. Пятёрку из пяти карточек не выкидывать, пока не скажешь: читер и комната анимаций живут как жили.

## 3. Сейв — три разных ящика, не мешать

| Ключ `localStorage` | Что |
|---|---|
| текущий сейв ключа (`SAVE_KEY`) | один заход: маршрут, таймер, HP отряда |
| `mythicKeyProfile_v1` | лобби: пятёрка, данж, уровень ключа |
| `igorLevelingPaladin_v1` | песочница паладина — не читать из Теста |
| **новый** `igorHero_v1` | прокачка на Тесте |

Черновик `igorHero_v1`:

```
{
  v: 1,
  activeId: "h_ab12",
  heroes: [{
    id: "h_ab12",
    name: "…",
    classId: "paladin",
    specId: "retribution",
    level: 1,
    xp: 0,
    talents: { t1: "speed_of_light", t2: null, t3: null, t4: null, t5: null },
    firstClears: { crypts: true },
    stats: { instances: 0, kills: 0, wipes: 0 },
    created: 0
  }]
}
```

Правила сейва:

- Герой **не** лежит внутри сейва ключа. Вайп ключа не стирает уровень.
- Экспорт профиля ключа (`save.js`) позже может **приложить** `hero` отдельным полем. Не сейчас.
- Версия `v`. Старый сейв без поля — отказать, не чинить молча.
- Один активный герой. Массив `heroes` сразу, чтобы потом не ломать формат, но в UI сначала один слот.
- Сброс героя — отдельная кнопка в таверне, не «сбросить ключ».

## 4. Инст прокачки ≠ ключ

Ключ на Тесте и основе уже без привала. Инст прокачки тоже **без привала**, иначе пальцы учатся другому.

Короткий маршрут (как в концепте, минус привал):

`3 треша → элита → страж → финал`

Между пачками как в ключе: ≈6% от недостающего HP, мана почти не капает, вторичный ресурс в стартовое (Энергия Света = 3 и т.п.).

Скобки данжей те же имена: Склеп 1–12 · Кузня 8–20 · Приливник 16–28 · Монастырь 24–36 · Чертоги 32–40. Без аффиксов ключа.

## 5. Когда что открывается (шаблон на все классы)

Не 1–90. Не wowhead. Кит **этой** игры.

| Ур. | Что появляется |
|---|---|
| 1 | Одна копилка / один удар / один простой хил |
| 4 | Вторая кнопка оси (Правосудие, Лунный огонь, Яростный выпад…) |
| 8 | Первый спендер **или** первый именной эффект + **ярус I** |
| 12 | Служебное: провокация / кик / пет / хот |
| 16 | Вторая ось (область или длинный дот) + **ярус II (ресурс)** |
| 20 | Казнь / сейв / без хода |
| 24 | Лицо спека + **ярус III** |
| 28–32 | Большой кулдаун + **ярус IV** |
| 40 | Потолок кита + **ярус V** |

Пассивки спека (искусность, Дар хмелевара, Искупление, Серия приёмов) — не с 1-го. Обычно **10–14**, когда уже есть что усиливать.

Готовый стол паладина — в `КОНЦЕПТ.md`. Остальные классы **не выдумывать ночью пачкой**: на утро идти по одному классу и сверять с листом «Кнопки» + «Слабые стороны».

## 6. Таланты — смотреть таблицу, не «подтянуть слабых»

Файл: `сравнение_ролей.xlsx`. Это жадная модель на 12 ходов, не живой ключ. **Нельзя** деревом чинить артефакты модели.

Что таблица врёт (не лечить талантом):

- Изобретатель сверху в СТ — S37 не крутили, не трогаем.
- Серийные (разбойник, Сила зверя) в СТ скромные: модель не сбрасывает раньше пятёрки и ест энергию.
- Воздаяние: в данных у Божественной бури 4 Энергии Света при потолке 3 — в таблице поставили 3.
- Хилы «с танком» — средний СТ всех хилов, не идеальный сейв.
- В 10 целях соло ни один танк не вывозит — это сетка, не приговор танку.

### Закон дерева

5 ярусов, **один из трёх**, уровни **8 / 16 / 24 / 32 / 40**.

| Ярус | Вопрос, на который отвечает |
|---|---|
| I шаг (8) | Как ходишь / первый укол |
| II ресурс (16) | Как кормишь бар (ярость, мана, серия, руны, пар…) |
| III лицо (24) | **Разный у каждого спека.** Иначе дерево врёт |
| IV приём (32) | Раз в бой / раз в инст. Не +% навсегда |
| V венец (40) | Маленький потолок: иск. / живучесть / удар. Не новая кнопка |

Запреты:

- Не плюсовать голый урон, чтобы догнать соседа по столбцу «СТ 1».
- Не давать танку второй полный самохил «потому что в таблице 0» — это **выбор** на ярусе III/IV, не бесплатная заплатка всем танкам.
- Не смешивать с `TALENTS` ключа.
- Не писать ветку Изобретателю.
- Сапёр (S36) забит — дерево не начинать, пока кит не живой.

### Как читать «Слабые стороны» при сочинении ветки

Дыра в таблице = **тема развилки**, не обязательный баф.

| Спек | Дыра в таблице | Что предлагать на развилке (черновик, не цифры) |
|---|---|---|
| Воин Оружие | Слабо растёт в 5 | III: жирнее «Кровотечение» **или** «Широкий размах» чаще **или** Мощный удар дешевле. Не третий вихрь. |
| Воин Защита | Нет самохила | III/IV: малый вампиризм с Реванша **или** толще блок **или** Глухая оборона −КД. Один из трёх. |
| Паладин Защита | Нет самохила | Уже есть стол в концепте (оплот / земля / дух). Не добавлять четвёртый хил. |
| Паладин Свет | Мана на длинном | II уже про ES. III: дешевле Вспышка **или** жирнее Слово славы **или** щит. Не +50% хила. |
| Жрец Послушание | Хилы через урон | III: толще Искупление **или** толще щит **или** Кара жирнее. Игрок выбирает, чем кормить. |
| Жрец Тьма | Почти нет области | III: маленькая область с Боли **или** жирнее СТ **или** быстрее сферы. Не Звездопад. |
| Разбойник все | Серия / ранний слив | II: кривая мягче с 3 очков **или** генератор +1 **или** финишер не ест ниже 3. Не +20% Потрошения. |
| Сила зверя | Та же серия | Тот же ярус II, что у разбойника. Дикий рёв серию не ест — не ломать. |
| Охотник все | Урон на питомце | III: пет жирнее / живее **или** хозяин без пета **или** уникальный баф пета (это уже в бэклоге). |
| Монах Ветер | 5/СТ низкий | III: журавль жирнее **или** Восходящее жирнее **или** ци с Лапы +1. |
| Монах Хмелевар | Самохил = 0 в модели | Дар хмелевара уже пассивка. III: дар чаще **или** толще пошатывание **или** уклон. Не второй лотос. |
| Друид Страж | Нет самохила | III: Неистовое +% **или** толще броня **или** Взбучка вампирит. |
| Рыцарь смерти Кровь | Самохил от Удара смерти | Не усиливать Удар смерти всем деревом. III: руны чаще **или** щит толще **или** окно полученного длиннее. |
| Шаман Исцеление | СТ скромный, область сильная | III: Цепь жирнее **или** СТ всплеск **или** тотем. Не выравнивать с Послушанием. |

Ярусы I / IV / V можно держать **классовыми** (общие на 3 спека), ярус III — только спековый. Так у паладина уже сделано.

## 7. Порядок работ, когда скажешь «делай»

Не всё сразу. Один шаг — потом стоп.

1. **Кривая + сейв `igorHero_v1` + таверна-заглушка** в Тесте. Без боя. Создал паладина Защиты — лежит в `localStorage`, лобби ключа его видит плашкой.
2. **Открытие кнопок паладина** из живого кита (сверить с концептом). Бой — короткий инст на движке Теста.
3. **Дерево паладина** перенести из песочницы как есть. Сброс в таверне.
4. **ИИ пати** урезанный. Игрок ходит только своим.
5. Следующий класс — **воин** (три роли нет, но три спека и дыры в таблице ясные). Потом жрец, монах. Дальше по списку S.
6. На 40-м — крючок «этот герой = слот 1 ключа». Пятёрку лобби не ломать, пока не скажешь.

Песочницу `прокачка/` не удалять: это эталон кривой и дерева паладина, пока Тест не повторит её один в один.
