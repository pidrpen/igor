# Предложения ИИ — 2D стили персонажей

Референс: `Мои пожелания/` (паладин слева · дух/Ша справа).  
Кропы: `_ref_crops/`.

Все вариации — **пара в одном кадре**: слева паладин (золотая броня + меч), справа фиолетовый дух с оранжевыми глазами.

## Как выбрать

- **Нужны пиксельные анимации ударов** → смотри **02 / 03 / 07** (проще резать на кадры).
- **Хочешь «дорого» и близко к рефу** → **03** или **04**.
- **Тёмный мифик-муд** → **05**.
- **Ярко и по-аниме** → **06**.
- **Милота** → **01**.

Напиши номер стиля (или несколько) — закрепим его и начнём делать спрайт-сеты (idle/attack) уже в этот look.
