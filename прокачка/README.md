# Песочница прокачки (паладин 1–40)

Отдельная папка. **Основу и `Тест/` не трогает.**

## Запуск

Из корня репозитория (чтобы портреты и фоны нашлись в `assets/`):

```bash
python -m http.server 8080
```

Открой http://localhost:8080/прокачка/

Или из этой папки — тогда картинки не подтянутся (`../assets`). Сервер лучше держать в корне.

## Что здесь

- Один паладин: Свет / Защита / Воздаяние
- Уровни 1–40, опыт с пачек и зачистки
- Дерево: ярусы 8 / 16 / 24 / 32 / 40, один из трёх
- Поиск инста: случайный данж по уровню + 4 рандомных ИИ под роли
- Короткий маршрут, пошаговый бой, мана и Энергия Света как в основе

Концепт и зачем так: [`КОНЦЕПТ.md`](КОНЦЕПТ.md).

Сейв: `localStorage` ключ `igorLevelingPaladin_v1`. Сброс — кнопка в таверне.

Отладка: +1 уровень, +400 опыта, сразу 40 — чтобы пройти кривую без двадцати инстов.
