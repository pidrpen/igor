Обновлять в том же ходе, если файл или дом фичи сдвинулся. Не дублировать журнал (`SESSION.md`) и жёлтые решения (`СЕССИЯ_разбор_баланса.md`).

```bash
# тест
cd igor-main/Тест
python -m http.server 8080
# http://localhost:8080/

# Phaser-арена (песочница поля, не ключ)
# http://localhost:8080/phaser-арена/

# живой бой (реальное время, не ключ)
# http://localhost:8080/живой-бой/

# изометрия Godot (не HTML): открыть iso-key/project.godot в Godot 4.3, F5

# пробы геймплея (Намерения, Пулл): http://localhost:8080/прототипы/

# лаунчер вместо сервера: запустить launcher/MythicKey.exe → основа на http://127.0.0.1:47619/, Тест на /Тест/

# прокачка — сервер из корня игры (igor-main/ или клон), иначе ../assets не найдутся
# http://localhost:8080/прокачка/
```
