# MythicKey.exe — лаунчер

Один файл, установка не нужна, права администратора не нужны.

## Как играть

1. Скачай `launcher/MythicKey.exe` из репозитория и положи куда удобно (рабочий стол, «Загрузки»).
2. Запусти. Первый раз он скачает игру — около 230 МБ, дальше только то, что изменилось.
3. Игра откроется отдельным окном Edge, без адресной строки. Закрыл окно игры — лаунчер через несколько секунд закрылся сам.
   Он следит не за процессом Edge (тот может перезапуститься сам), а за отметками самой страницы игры раз в 5 с.

Windows при первом запуске может показать «Система Windows защитила ваш компьютер»: exe не подписан.
«Подробнее» → «Выполнить в любом случае».

## Как выходят обновления

Никак отдельно: **пушнул в `main` — у всех обновилось при следующем запуске.**

- Лаунчер спрашивает у GitHub последний коммит `main` и список файлов в нём, сверяет каждый файл
  по git-хешу и докачивает только изменённые (битый файл не сохраняется).
- Файлы берёт с `raw.githubusercontent.com`, если не отвечает — с `cdn.jsdelivr.net`, потом с `github.com`.
- Новый `launcher/MythicKey.exe` в `main` — лаунчер заменит сам себя (старый переименует в `.old` и уберёт).
- Нет интернета — откроет уже скачанное.

## Что где лежит на компьютере игрока

`%LOCALAPPDATA%\MythicKey\`

| Папка / файл | Что это |
|---|---|
| `test\game\` | скачанная игра (папка `Тест/` репозитория) |
| `browser\` | профиль окна игры: здесь живут локальные сейвы (localStorage) |
| `launcher.log` | журнал: что скачал, что не смог — первое, что смотреть при проблеме |

## Настройки (необязательно)

Файл `launcher.ini` рядом с exe:

```ini
channel=test      ; test — папка Тест/ (по умолчанию), main — основа
branch=main       ; с какой ветки брать игру
no_self_update=1  ; не обновлять сам exe
browser=C:\путь\к\browser.exe  ; свой браузер (Chrome, Яндекс) вместо Edge
```

Тест открывается на `http://127.0.0.1:47619/`, основа — на `:47620`. Порты постоянные: от адреса
зависит, где браузер хранит сейв, поэтому их не менять.

Что не качается: `.md`, `.xlsx`, `.py`, `.csv`, папки `tools/`, `tests/`, `game-parts/`, `предложения ИИ/`.
Ссылка «← Основная игра» из Теста в лаунчере не работает: в канале `test` скачан только Тест.

## Сборка exe

```sh
sh launcher/build.sh   # нужен mingw-w64: apt install gcc-mingw-w64-x86-64 binutils-mingw-w64-x86-64
```

Кладёт `launcher/MythicKey.exe` (~100 КБ). Номер версии — `launcher/version.h`.
Закоммитил exe в `main` — у всех обновится сам.
